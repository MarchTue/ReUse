### 주요 변경사항: 모바일 신분증 인증 구현 (feat/#28)

RAON에이전트를 활용한 모바일 신분증 인증 플로우를 구현하여 사용자의 신원을 안전하게 확인할 수 있도록 했습니다. 이 과정은 사용자 가입의 필수 단계로, 보안과 신뢰성을 확보하는 데 중점을 두었습니다.

* **RAON 인증 통합:**
    * 모바일 신분증을 인증하고, 신규 사용자 가입 여부를 확인하는 API 호출 로직을 구현했습니다.
    * RAON 토큰 파싱 및 CI(Connecting Information) 해싱 API 엔드포인트를 리팩토링하여 보안성과 효율성을 높였습니다.
    * **`axios`**와 **`bcrypt`** 패키지를 추가하여 외부 API 연동 및 데이터 암호화를 지원합니다.
* **사용자 및 인증 관련 타입 정의:**
    * 사용자 관련 타입 및 `enum`을 추가하여 데이터 구조를 명확히 하고 코드의 안전성을 높였습니다.
    * **`uuid`** 패키지를 추가하여 고유 식별자 생성에 활용합니다.
* **Redis 기반 인증 데이터 관리:**
    * Next.js API 라우트를 통해 **Redis** 데이터베이스에 인증 관련 정보를 저장하고 조회하는 기능을 추가했습니다.
    * Docker 컨테이너 환경에서 개발할 수 있도록 `docker-dev` 스크립트가 포트 30001을 사용하도록 업데이트했습니다.
    * Redis 클라이언트 구현 및 `package.json` 업데이트를 통해 Redis 연동 환경을 구축했습니다.
* **인증 페이지 및 라우팅:**
    * 초기 `VerificationPage` 컴포넌트가 `OnboardingPage`에서 라우팅되도록 변경되었으며, 스크립트 로딩 및 에러 처리가 개선되었습니다. (이전 0.2.0 버전과 연결)
    * 사용자 인증 처리를 위한 **`AuthGuard`** 컴포넌트를 추가하여 인증 상태에 따른 페이지 접근을 제어합니다.

### 주요 변경사항: 회원가입 플로우 전반 구현 (feat/#35)

사용자의 원활한 회원가입 경험을 제공하기 위한 다단계 회원가입 플로우가 구현되었습니다. 이는 닉네임 설정, 약관 동의, 계좌 선택, 추가 정보 입력 등 여러 단계를 포함하여 사용자 온보딩 과정을 완벽하게 지원합니다.

* **닉네임 입력 및 중복 확인:**
    * 사용자가 닉네임을 입력하고 실시간으로 중복 여부를 확인할 수 있는 기능을 추가했습니다.
    * 닉네임 컴포넌트에 타이머 관련 설정 및 개선된 에러 메시지를 적용하여 사용자 피드백을 강화했습니다.
    * 관련 **테스트 코드**를 추가하여 기능의 안정성을 확보했습니다.
* **약관 동의 컴포넌트:**
    * 필수 및 선택 약관에 대한 동의 기능을 구현하고, 관련 **테스트**를 추가했습니다.
    * 회원가입 단계에서 약관 동의 여부를 관리하고 다음 단계로 진행할 수 있도록 로직을 개선했습니다.
* **계좌 선택 및 은행 정보 관리:**
    * 회원가입 과정에서 사용자가 자신의 계좌를 선택할 수 있도록 컴포넌트를 추가했습니다.
    * **Radix UI**의 `react-popover` 패키지를 활용하여 계좌 선택 UI의 사용자 경험을 향상했습니다.
    * 은행 정보에 대한 타입 정의 및 목록을 추가하여 데이터를 체계적으로 관리합니다.
* **추가 정보 입력 및 제출 처리:**
    * 회원가입을 위한 추가 데이터 및 약관 동의 정보에 대한 인터페이스를 정의했습니다.
    * 폼 제출 처리 로직과 단계 전환 로직을 추가하여 전체 회원가입 과정을 매끄럽게 연결했습니다.
    * **Mock 데이터**를 연동하여 개발 초기 단계에서 API 의존성 없이 기능을 테스트할 수 있도록 했습니다.
* **컴포넌트 및 스타일 개선:**
    * 새로운 **`Input` 컴포넌트**를 추가하고, 기존 `Input` 컴포넌트의 코드 스타일을 수정하여 재사용성과 일관성을 높였습니다.
    * `SignupUserNickname` 컴포넌트의 `props` 타입을 변경하고 인터페이스를 분리하여 코드의 가독성과 유지보수성을 향상했습니다.
    * `WalletPlatformEnum`의 대문자 표기법을 적용하는 등 타입 관련 일관성을 유지했습니다.
    * **Tailwind CSS** 및 **PostCSS** 관련 의존성 및 설정을 업데이트하여 스타일링 환경을 최적화했습니다.
