## 주요 변경사항

### 1. 홈 화면 구성 (feat/#41)

사용자가 애플리케이션에 로그인했을 때 처음 보게 될 **홈 화면**을 구성했습니다. 이 화면은 주요 기능에 대한 진입점 역할을 합니다.

* **홈페이지 구조 변경:** 기존 홈페이지 구조를 변경하여 사용자 친화적인 레이아웃을 제공합니다. 이는 주요 정보나 서비스에 빠르게 접근할 수 있도록 설계되었습니다.
* **서버 데이터 함수 주석 추가:** 홈 화면에서 필요한 서버 데이터 연동 함수에 대한 주석을 추가하여 코드의 이해도를 높이고 향후 개발 편의성을 제공합니다.
* **색상 팔레트 확장:** `tailwind.config.ts` 파일에 `grad` 색상 팔레트를 추가하여 홈 화면 및 기타 UI 요소에 다채롭고 시각적으로 매력적인 그라데이션을 적용할 수 있도록 했습니다.

### 2. 핵심 내비게이션 컴포넌트 추가

애플리케이션 전반에서 사용될 핵심 내비게이션 컴포넌트들을 추가하여 사용자 경험을 일관되고 직관적으로 만듭니다.

* **앱 헤더 컴포넌트 (`AppHeader`):**
    * 애플리케이션 상단에 고정될 `AppHeader` 컴포넌트를 추가했습니다. 이 헤더는 일반적으로 로고, 타이틀, 알림 또는 사용자 설정과 같은 요소를 포함합니다.
    * `AppHeader` 컴포넌트에 대한 테스트 코드를 추가하여 컴포넌트의 기능과 렌더링이 예상대로 동작하는지 확인합니다.
* **바텀 내비게이션 컴포넌트 (`BottomNavigation`):**
    * 모바일 환경에서 주로 사용되는 `BottomNavigation` 컴포넌트를 추가했습니다. 이를 통해 사용자는 앱의 주요 섹션 간을 쉽게 이동할 수 있습니다.
    * 내비게이션 탭에 대한 상수를 정의하여 코드의 재사용성과 유지보수성을 높였습니다.
    * `BottomNavigation` 컴포넌트에 대한 테스트 코드를 추가하여 안정적인 동작을 보장합니다.
